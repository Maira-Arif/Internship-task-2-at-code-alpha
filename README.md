# 📈 Stock Portfolio Tracker (Python)

## 📌 Description
This is a simple **Stock Portfolio Tracker** developed using Python. It allows users to create a basic stock portfolio by selecting stocks from a predefined list and entering the quantity of shares they want to track.

The program calculates the total value of each stock and the overall investment. It also saves the portfolio summary in a text file (`portfolio.txt`) for future reference.

## 🚀 Features
- Displays a list of available stocks.
- Allows users to select stocks by entering stock symbols.
- Takes the number of shares as user input.
- Calculates the total value of each stock.
- Supports multiple stock entries.
- Handles invalid stock names.
- Handles invalid quantity inputs.
- Displays a complete portfolio summary.
- Saves the final portfolio summary in a text file.

## 🛠️ Technologies Used

- Dictionary
- While Loop
- For Loop
- If-Else Statements
- Try-Except Exception Handling
- File Handling

## ▶️ How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Run the Python file:
   ```bash
   python main.py
   ```

4. Enter the stock symbols and quantities.

5. Type `done` when you finish adding stocks.
